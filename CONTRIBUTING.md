# Contributing to Awesome Memecoin Trading

The memecoin space ships daily. The list only stays useful with community help. Thanks for taking the time to contribute.

## Quick rules

- **Live tools only** (or public-testnet, marked 🟡). Abandoned tools get marked 🔴 or removed.
- **One entry per row**, alphabetical-ish within sub-groupings where possible.
- **Match the column structure** of the section you're editing.
- **Use the legend** consistently:
  - 🟢 Live · 🟡 Beta / Limited · 🔴 Inactive · ⚡ Top-volume · 🆕 Launched 2025/26 · 🎟️ Affiliate link
- **No referral spam.** Max one affiliate link per row. Only mark 🎟️ if you've verified the link works.

## What we accept

- Memecoin launchpads (any chain)
- Trading terminals & front-ends targeting memecoin trading
- Telegram trading bots
- Sniper bots & new-launch detection tools
- Trenches / pre-bonding-curve scanners
- Copy trading platforms
- Smart-money / wallet / PnL trackers
- Memecoin scanners, charting tools, holder visualizers
- Bundle / sandwich / insider detection tools
- Rug detection / token safety tools
- AI memecoin agents and tools
- Memecoin news, sentiment, and InfoFi platforms
- DEXs where memecoins trade
- Mobile apps & wallets meaningful for memecoin traders
- Block explorers
- Tax tools that handle memecoin / DeFi complexity
- MCPs for memecoin AI agents
- Infrastructure (RPCs, indexers, APIs) used by memecoin builders
- Notable memecoins worth tracking
- KOLs / Twitter accounts / YouTube channels (must be useful, not promotional)

## What we don't accept

- Pure marketing pages with no working product
- Abandoned tools (open an issue if you spot one)
- CEXs that aren't memecoin-focused
- Outright scams or known-rugger projects
- Spammy or vague entries
- Affiliate-link spam
- Duplicates — please grep the README first

## How to submit

1. Fork the repo
2. Create a feature branch (`feature/add-foo-bot`)
3. Edit the relevant section
4. Open a PR with:
   - Project name + URL
   - One-line description
   - Why it belongs in the section you placed it in
   - Optional: chain, fee, leverage, status stats you can verify

## Reporting issues

Found a broken link, dead project, or stale stat? Open an issue or PR with a quick note.

## Affiliate links

If you're a project owner and want to update / add an affiliate link to your row, that's fine — but please disclose in the PR description. Affiliate links must:

1. Lead directly to the project's referral page (no cloaked redirectors)
2. Replace, not duplicate, an existing entry
3. Be marked 🎟️
